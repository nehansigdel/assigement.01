My Web Development Experience

Developing this portfolio website has been a useful experience because it has helped me understand the basics of web development. Before starting this project, I had limited experience with creating websites. I started by learning HTML and understanding how different elements are used to create the structure of a webpage.

HTML was one of the first technologies I learned. I learned how to use headings, paragraphs, images, links, lists, tables and forms. I also learned about semantic elements such as header, navigation, main, section, article and footer. Using these elements helped me organise my webpages more clearly.

After learning HTML, I started working with CSS. CSS was useful because it allowed me to change the appearance of my website. I used CSS to add colours, fonts, spacing, borders and layouts. I also learned about Flexbox and CSS Grid. These were initially difficult, but practising with different layouts helped me understand them better.

One of the challenges I experienced was getting images to display correctly. Sometimes an image did not appear because the file path was incorrect. I solved this by checking my folder structure and making sure the image name in the HTML matched the actual filename.

I also had some problems with the website layout when changing the size of the browser window. Some content did not fit properly on smaller screens. I used CSS media queries to make the website responsive. Testing the website on different screen sizes helped me understand why responsive design is important.

Another useful part of the project was debugging. When something did not work, I checked my HTML and CSS carefully and used the browser developer tools to find problems. This taught me that debugging is an important part of web development.

Overall, I enjoyed developing this portfolio because it allowed me to combine HTML and CSS to create a complete website. There were some difficult moments, but solving the problems helped me become more confident. In the future, I would like to improve this website by adding my actual university projects and learning more advanced technologies such as JavaScript.
